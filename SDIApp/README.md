# SDIApp

Однодокументное (SDI) приложение MFC: в основном окне рисуется график синуса и связанные с ним элементы (оси, дуги, штриховки). Слева — дерево с флажками слоёв (`MyTreeView`): можно включать и выключать синус, оси и виды кисти.

Есть пункты меню (линия) и стандартные команды файла/печати. Сборка: `SDIApp.sln`.
