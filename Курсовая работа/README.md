# Курсовая работа — сборка механизма

Папка с графическими файлами сборки (`.grs`) и презентацией `ОПМ.pptx`.

В `сборка_курсовая` лежит механизм: кривошип, шатуны, коромысло, ползун, стойки, оси, водило, двигатель и итоговая сборка `Сборка_курсовая.grs`. Это курсовой проект по теории механизмов / деталям машин (не исходники C++).
