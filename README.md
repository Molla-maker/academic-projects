# Учебные проекты

Сборник лабораторных, курсовых и учебных программ с диска `D:\Projects`.

| Папка | Что это |
| --- | --- |
| [4lab](4lab) | 25 консольных задач на динамические матрицы в C++ |
| [coursework](coursework) | Курсовая: построение 3D-детали в КОМПАС-3D из MFC |
| [IntegrationMethodsComparison](IntegrationMethodsComparison) | Сравнение методов численного интегрирования |
| [TranscendentalEquationSolver](TranscendentalEquationSolver) | Решение трансцендентного уравнения (Ньютон, дихотомия, хорды) |
| [Задание 2](Задание%202) | Численное интегрирование функции `(4.5 − x) · ctg(π/x)` |
| [MyMFCApp](MyMFCApp) | Учебное диалоговое приложение на MFC (элементы управления) |
| [SDIApp](SDIApp) | SDI-приложение: график синуса с деревом слоёв |
| [projects-gallery-Molla-maker](projects-gallery-Molla-maker) | Веб-галерея 3D-моделей (Express, SQLite, Three.js) |
| [Курсовая работа](Курсовая%20работа) | Сборка механизма (кривошип, шатун, ползун) и презентация |
| [HelloNRX](HelloNRX.md) | Заготовка плагина NRX для nanoCAD / AutoCAD |
| [nanocad-labs](nanocad-labs) | Лабораторные nanoCAD: решение NCadSDK и проект HelloNRX |
| [Детмаш](Детмаш) | Детали машин: вал, муфта, подшипники (КОМПАС) и кинематика (Mathcad) |

Исходники MFC-проектов открываются в Visual Studio (файлы `.sln`). Веб-проект запускается через Node.js.
