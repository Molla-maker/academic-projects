# Тест-кейсы для ручного тестирования приложения «Заказ доставки»

## Описание приложения
Приложение для оформления заказа доставки с полями: адрес, время, товары, сумма, комментарий.

## Правила валидации полей
| Поле | Тип данных | Ограничения |
|------|------------|-------------|
| Адрес доставки | Строка | 5-200 символов, обязательное |
| Время доставки | Время | Формат ЧЧ:ММ, часы 0-23, минуты 0-59 |
| Товары | Строка | Минимум 1 товар через запятую, обязательное |
| Сумма заказа | Целое число | 100-100000, обязательное |
| Комментарий | Строка | Необязательное, макс 500 символов |

---

## Тест-кейс TC-01
**Название:** Успешное оформление заказа с корректными данными  
**Предусловия:** Приложение открыто  
**Шаги:**
1. Ввести адрес: "ул. Ленина, д. 10, кв. 5"
2. Ввести время: "14:30"
3. Ввести товары: "Хлеб, Молоко, Сыр"
4. Ввести сумму: "1500"
5. Ввести комментарий: "Позвонить за 10 минут"
6. Нажать кнопку «Ок»

**Ожидаемый результат:** Сообщение «Успешно» с данными заказа
