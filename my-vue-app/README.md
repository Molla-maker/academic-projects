# my-vue-app — тест по физике на Vue 3

Учебное SPA на Vue 3 + Vite: викторина из 10 вопросов по механике (инерция, импульс, законы Ньютона, работа и энергия). Вопросы и логика теста живут в `src/components/HelloWorld.vue`, оформление — в `physics.css`.

Запуск:

```bash
cd my-vue-app
npm install
npm run dev
```

Сборка: `npm run build`. Каталог `node_modules` в репозиторий не входит.
