# IntegrationMethodsComparison

MFC-диалог для численного интегрирования функции \(f(x) = (4.5 - x) / \tan(\pi / x)\) на заданном отрезке.

Доступны методы:

- прямоугольников;
- трапеций;
- Симпсона (парабол).

Кнопки считают значение интеграла и оценивают точность. Сборка: `IntegrationMethodsComparison.sln`.
