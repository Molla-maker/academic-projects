# Детмаш — модели и расчёты по деталям машин

Учебные файлы курса «Детали машин»: 3D-модели и чертежи в КОМПАС-3D, расчёты в Mathcad.

| Папка | Содержимое |
| --- | --- |
| [вал](вал) | Модели вала (`.m3d`) и чертежи (`.cdw`) |
| [муфта](муфта) | Сборка фланцевой муфты `МПСТ.000` и деталь полумуфты |
| [подшипник](подшипник) | Сборка подшипника: наружное/внутреннее кольца, полусепаратор |
| [подшипник2](подшипник2) | Отдельная модель подшипника |
| [курсач](курсач) | Кинематический расчёт в Mathcad (`.mcdx`) |

Открывать модели и чертежи в КОМПАС-3D, расчёты — в PTC Mathcad. Резервные копии `*.bak` в репозиторий не входят.
