# 4lab — задачи на двумерные массивы

Набор из 25 отдельных консольных программ на C++ (каждая задача — своё решение Visual Studio). Программы работают с динамической квадратной матрицей `N×N`: пользователь задаёт размер и элементы, затем выполняется одно преобразование.

Типичные операции: обмен минимума и максимума, сортировка строк и столбцов, работа с главной и побочной диагоналями, обнуление по условию, транспонирование, средние и геометрические средние по строкам.

Запуск: открыть `TaskNN/TaskNN.sln`, собрать и выполнить в консоли. Локаль вывода — русская (`setlocale`).
