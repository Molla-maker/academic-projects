# coursework — параметрическое моделирование в КОМПАС-3D

Диалоговое приложение на MFC, которое через COM API КОМПАС-3D (версия SDK *KOMPAS-3D v22 Study*) создаёт трёхмерную деталь: эскизы на плоскостях, выдавливания и вспомогательные плоскости. Длина/параметр задаётся в поле диалога (`m_long`, по умолчанию 55).

Нужны установленный КОМПАС-3D Study и пути к `kAPI5.tlb` / заголовкам SDK, как в `courseworkDlg.cpp`. Сборка: `coursework.sln`.
