# Задание 2 — численное интегрирование

Диалоговое MFC-приложение. Считается интеграл функции \(f(x) = (4.5 - x) \cdot \mathrm{ctg}(\pi / x)\) на отрезке \([2.4; 4.08]\) (границы можно править в полях).

Три радиокнопки выбирают метод:

1. прямоугольников (средние точки);
2. трапеций;
3. Симпсона.

Сборка: `Задание 2.sln`.
