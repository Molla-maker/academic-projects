# Molla Maker — галерея 3D-моделей

Веб-приложение курса Frontend: сервер на Node.js (Express) с регистрацией/входом, SQLite, загрузкой STL и просмотром моделей. Клиент использует Three.js.

- Запуск: `npm install`, затем `npm start` (порт 3001).
- Нагрузочные скрипты: `npm test` / `load-test.js`.
- Учебные этапы лежат в `lab1`–`lab4` и `1 lab` / `2 lab`.

Отдельный git-remote курса: `https://github.com/FrontendCourseMP/projects-gallery-Molla-maker` (ветка `basic-server`). Каталог `three.js` — локальный клон библиотеки, в общий репозиторий не кладётся (слишком большой).
